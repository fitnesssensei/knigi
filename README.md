ГОРЫ-КНИГ — статический сайт букинистического магазина
=======================================================

ЧТО ЭТО
Витрина магазина в двух версиях: настольная и мобильная, плюс страница
выбора версии. Каталог, фильтры, избранное, корзина и оформление заказа
работают в браузере, без сервера. Данные каталога — статичный массив
в assets/js/data.js (14 демонстрационных лотов).

БЫСТРЫЙ СТАРТ
1. Соберите сайт: node scripts/build-site.js
   Требуется Node.js 18+; npm-зависимостей и установки пакетов нет.
2. Откройте dist/index.html двойным щелчком и выберите версию.
3. Прогон автотестов: node --test

Почему нужна сборка: страницы в dist/ автономные — CSS, JS и шрифты
встроены прямо в HTML (шрифты в base64), поэтому открываются с диска
без интернета и веб-сервера. В репозитории хранятся только исходники,
папка dist/ в .gitignore.

СТРУКТУРА
src/pages/            index.html, desktop.html, mobile.html — шаблоны страниц
src/partials/shared/  overlay, drawer-cart, drawer-favorites, modal, toasts
src/partials/desktop/ header, hero, catalog, about, subscribe, footer, noscript
src/partials/mobile/  header, hero, catalog, about, subscribe, footer,
                      drawer-menu, drawer-filter, noscript
assets/css/           fonts.css, base.css, desktop.css, mobile.css
assets/js/            data.js (каталог), shop.js (логика магазина)
assets/fonts/         woff2-шрифты и лицензии
scripts/              build-site.js (CLI), lib/build.js (логика сборки)
tests/                автотесты на node:test + tests/helpers/dom.js (DOM-стаб)
dist/                 результат сборки (в git не попадает):
                      index.html, desktop.html, mobile.html, gory-knig-site.zip

КАК ПРАВИТЬ
• Вёрстка — в src/partials/. Общие блоки (панели корзины и избранного,
  модальное окно, оверлей, тосты) лежат в src/partials/shared/ и меняются
  сразу для обеих версий.
• Тексты, цены, лоты — assets/js/data.js.
• Фильтры, корзина, избранное — assets/js/shop.js.
• После любой правки исходников: node scripts/build-site.js (сборка)
  и node --test (автотесты).

Директивы в шаблонах страниц: include занимает целую строку
<!-- include: partials/mobile/header.html --> и подставляется при сборке.

СБОРКА
node scripts/build-site.js
1. склеивает шаблоны src/pages/*.html с partials;
2. встраивает <link rel="stylesheet"> и <script src> в HTML;
3. переводит шрифты assets/fonts/*.woff2 в data:font/woff2;base64;
4. пишет dist/index.html, dist/desktop.html, dist/mobile.html;
5. собирает архив dist/gory-knig-site.zip:
   gory-knig/desktop.html, gory-knig/mobile.html, gory-knig/licenses/.

АРХИВ ДЛЯ ПЕРЕДАЧИ
dist/gory-knig-site.zip — те же автономные страницы. Распаковать,
получится папка gory-knig, открыть desktop.html или mobile.html.
Интернет и веб-сервер не нужны.

ТЕСТЫ
Команда: node --test
Ничего устанавливать не нужно (встроенный тест-раннер Node.js 18+,
сторонних библиотек нет). Сейчас 35 тестов, все проходят.

tests/build.test.js          сборка: 3 страницы + архив, автономность
                             (нет ссылок на assets/), шрифты в base64,
                             детерминизм, состав zip, ошибка при
                             отсутствующем partial, inlineAssets
tests/pages.test.js          partials (все подключены, лишних нет) и
                             разметка страниц: id уникальны, поиск в
                             шапке, бургер-меню, жанры в меню, сортировка
                             в фильтрах, общие панели по одному разу
tests/shop.catalog.test.js   каталог на реальных данных: рендер 14 книг,
                             поиск, жанр, цена, редкости, сортировки,
                             сброс фильтров
tests/shop.cart.test.js      корзина и избранное, бейджи, localStorage,
                             оформление заказа, подписка, уведомления
tests/shop.menu.test.js      аккордеон «Категории», открытие панели с
                             оверлеем и блокировкой прокрутки, Escape
tests/index.test.js          страница выбора версии на широком и узком экране

Особенности:
• тесты детерминированные: таймеры подменены и «прокручиваются» вручную,
  Math.random зафиксирован, сеть не используется;
• каждый тест работает в своём окружении (временные папки удаляются);
• CSS и визуальная вёрстка автотестами не покрыты — проверяется структура
  разметки и логика assets/js/shop.js; внешний вид проверяется глазами
  в dist/desktop.html и dist/mobile.html.

ЧТО УМЕЕТ САЙТ
Общее: каталог с поиском, фильтры (сохранность, цена до, только редкости),
сортировка, карточка книги, избранное, корзина, оформление заказа, подписка,
всплывающие уведомления.
Настольная версия: фильтры в левом сайдбаре, поиск в шапке, панели корзины
и избранного справа.
Мобильная версия: поиск во всю ширину под логотипом, кнопка «три полоски»
с меню (Новые книги, Категории с раскрывающимся списком жанров,
Бэстселлеры, Авторы, Вход), фильтры и сортировка в выезжающей панели,
корзина и избранное — в нижних панелях.

ДАННЫЕ И СОСТОЯНИЕ
• Каталог статичный: 14 лотов, цены и описания вымышлены.
• Корзина и избранное хранятся в браузере (localStorage):
  ключи gory-knig:cart:v1 и gory-knig:favs:v1.
• Заказ и подписка ничего не отправляют — показывают уведомление.
• Серверной части и API нет.

ОФОРМЛЕНИЕ
Палитра собрана в одном месте — assets/css/base.css, блок :root
(--paper, --ink, --violet, --lilac и др.). Меняя только эти значения,
можно перекрасить сайт целиком.

ШРИФТЫ
Cormorant Garamond и Inter, локальные файлы, лицензия SIL OFL 1.1
(тексты — assets/fonts/LICENSE-*.txt). В собранных страницах шрифты
встроены в HTML в base64.

GIT
Репозиторий: git@github.com:fitnesssensei/knigi.git, ветка main.
В .gitignore: .DS_Store, .clinerules, dist/ (сборка не коммитится —
её запускают перед выкладкой).

ОГРАНИЧЕНИЯ
• Визуальная часть (CSS, реальная вёрстка в браузере) автотестами не покрыта:
  проверяются структура HTML и логика shop.js, внешний вид — вручную.
• Телефон, адрес почты и пометки «демонстрационный проект» —
  заменители реальных данных.
• Подключение к реальной базе (Django-админка) не сделано: вместо
  assets/js/data.js планируется API.

ВАЖНО
• Правки делаются только в src/ и assets/ — содержимое dist/ теряется
  при пересборке.
• Не переименовывайте папки src/, assets/, scripts/: пути в сборке
  считаются от корня проекта.
• index.html, desktop.html и mobile.html в dist/ должны лежать рядом
  друг с другом — по этим именам они ссылаются между собой.
