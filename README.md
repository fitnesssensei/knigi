ГОРЫ-КНИГ — статический сайт (полностью офлайн)
===============================================

КАК ОТКРЫТЬ

1. Распакуйте архив в любую папку — получится папка gory-knig.
2. Двойной щёлчок по index.html — откроется страница выбора версии.
   • desktop.html — настольная версия
   • mobile.html  — мобильная версия (смотрите в режиме устройства в браузере)

Интернет и веб-сервер НЕ НУЖНЫ: все стили, скрипты и шрифты
(Cormorant Garamond, Inter) лежат внутри папки assets.

ОФОРМЛЕНИЕ
Палитра — оттенки фиолетового и сиреневого. Все цвета собраны в одном
месте: assets/css/base.css, блок :root (--paper, --ink, --violet, --lilac).
Меняя только эти значения, можно перекрасить сайт целиком.

ВАЖНО
• index.html, desktop.html и mobile.html должны оставаться рядом с папкой assets.
• Не переименовывайте папку assets и файлы внутри неё.
• Корзина и избранное сохраняются в браузере (localStorage), а не на сервере.
  В Chrome, Edge и Firefox они работают и при открытии файла с диска.
• Проверено в Chrome, Edge, Firefox, Safari 16+, Opera.

СТРУКТУРА
index.html    — страница выбора версии
desktop.html  — настольная версия
mobile.html   — мобильная версия
assets/css/   — стили (fonts, base, desktop, mobile)
assets/js/    — данные каталога и логика магазина
assets/fonts/ — локальные шрифты + лицензии

Шрифты распространяются по лицензии SIL Open Font License 1.1 —
тексты лицензий: assets/fonts/LICENSE-*.txt.
