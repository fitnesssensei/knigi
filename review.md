# Кодревью проекта ГОРЫ-КНИГ

Дата: 17.11.2026
Охват: `src/pages`, `src/partials`, `assets/css`, `assets/js`, `scripts/`, `tests/`.
Статус: только замечания, исправления не вносились.

## Критичные (ломают UX)

1. **Ссылки прячутся под sticky-шапкой.**
   `html { scroll-behavior: smooth }` (`assets/css/base.css:24`), но ни у одной секции
   нет `scroll-margin-top`; шапка 74 px на десктопе и ~100 px на мобиле
   (логотип + строка поиска). Переходы «Каталог» / «О магазине» из меню и футера
   обрезают заголовок секции.
   Файлы: `src/partials/mobile/catalog.html`, `src/partials/desktop/catalog.html`.

2. **Ввод в поиске шапки не показывает результат.**
   После фильтрации каталог остаётся ниже первого экрана, скролла к результатам нет.
   Обработчик Enter удалён вместе с панелью поиска.
   Место: `applySearch()` — `assets/js/shop.js:838`.

3. **Бейджи расходятся с содержимым корзины и избранного.**
   `renderBadges()` считает `state.cart.length` / `state.favs.length`
   (`assets/js/shop.js:283–288`), а списки строятся из `cartList()` /
   `favoritesList()` с отбрасыванием неизвестных id (`assets/js/shop.js:269–275`).
   Устаревший `localStorage` → бейдж «2», а в панели пусто.

## Средние

4. **`aria-label` кнопки «В корзину» не учитывает состояние.**
   `cardMarkup()` всегда пишет «Добавить в корзину: …» (`assets/js/shop.js:258`),
   хотя текст кнопки уже «В корзине». После перезагрузки с непустой корзиной
   подпись неверна до первого клика. Ожидаемо:
   `added ? 'Убрать из корзины: ' : 'Добавить в корзину: '`.

5. **Бургер без `aria-expanded` / `aria-controls`.**
   `src/partials/mobile/header.html`: состояние меню не озвучивается скринридером.
   У кнопки «Категории» атрибуты есть — нужно так же для кнопки меню.

6. **iOS-зум при фокусе на поле ввода.**
   Поиск в шапке и поле подписки имеют `font-size: 14px`
   (`assets/css/mobile.css:39`, `assets/css/mobile.css:128`) — Safari зумит
   страницу при фокусе на `<16px`. Нужно `16px` (или `font-size: max(16px, …)`).

7. **Нет `prefers-reduced-motion`.**
   Плавный скролл (`html`), переходы панелей и анимации тостов не отключаются
   при системной настройке «уменьшить движение».

8. **Дубли CSS в `assets/css/mobile.css:221–227`.**
   `.book-detail__buy` объявлен дважды (`gap` и `grid-column`),
   `.book-detail__note` и `.book-detail__buy` дублируют `grid-column: 1 / -1`.

9. **Нет публикационной обвязки.**
   Отсутствуют: `favicon` (+ `apple-touch-icon`), `og:` / `twitter:` теги,
   `canonical` (три страницы с одинаковым контентом), `robots.txt`,
   `sitemap.xml`, `404.html`.

## Мелкие

10. **Мёртвый селектор в JS.** `panel.querySelector('.drawer__close')`
    (`assets/js/shop.js:562`) — такого класса в проекте нет, работает только
    фолбэк `panel.querySelector('input, button')`. Удалить или добавить класс.

11. **Inline-стиль в разметке.** `src/partials/mobile/noscript.html:2`
    (`style="padding:0 16px 24px"`) — вынести в CSS-класс.

12. **`money()` зависит от ICU.** `Number.toLocaleString('ru-RU')`
    (`assets/js/shop.js:64`) в урезанных сборках Node/браузера даёт другой формат
    (в тестах окружение фиксировано).

13. **Сборка требует системный `zip`.** `scripts/lib/build.js:96`
    (`execFileSync('zip', …)`) — не работает на Windows без утилиты.
    В API уже есть флаг `makeArchive`, но в CLI он не проброшен.

14. **Инлайн ассетов по строгим шаблонам.** `scripts/lib/build.js:52–58`:
    `<link rel="stylesheet" href="…">` и `<script src="…"></script>` совпадают
    только в точном виде — добавление `defer`, `media`, `integrity` приводит к
    тому, что файл молча не встраивается.

15. **`fs.rmSync(dist)` удаляет папку целиком.** `scripts/lib/build.js:88`:
    ошибка в пути `dist` приведёт к потере данных; нужна проверка или флаг.

16. **Пункты меню без действий.** «Новые книги», «Бэстселлеры», «Авторы», «Вход»
    (по договорённости пока не работают) — для публикации это видимые пустые
    кнопки: лучше `disabled` + «скоро» либо скрыть.

## Что сделано хорошо

- `esc()` применяется ко всем текстовым полям разметки (`cardMarkup`,
  `bookDetailMarkup`) — база защищена от XSS при будущем подключении API.
- Мёртвого CSS нет: все 142 класса из `assets/css/*.css` используются
  в `src/` или `assets/js/shop.js`.
- Тесты детерминированные, DOM-стаб без зависимостей, сборка воспроизводима
  байт-в-байт.

## Пробелы в тестах

- desktop-версия фильтров (сайдбар) не покрыта;
- ветки валидации формы заказа (неверный телефон, email, отсутствие согласия);
- битый JSON в `localStorage`;
- бейджи и панели при неизвестных id в `localStorage`;
- CSS и визуальная вёрстка (нужен браузер).
